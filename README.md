# 📞 Call Center Performance Dashboard

## Overview

This project showcases an interactive Power BI dashboard developed to analyze call center performance and support operational decision-making through data visualization and KPI reporting.

The dashboard demonstrates how Power BI can be used to transform operational data into meaningful business insights that help managers monitor performance and identify improvement opportunities.

---

## Business Objective

The objective of this project is to provide a centralized dashboard that enables stakeholders to monitor call center operations and evaluate key performance indicators through interactive visualizations.
